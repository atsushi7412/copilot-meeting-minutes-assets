# Copilot 議事録作成アセット

Microsoft 365 Copilotで、会議の書き起こしと会議設定から根拠付きの議事録初稿を作るための研修用アセットです。人物・会社・組織・製品／サービスと呼び方のSSOTを整え、実行結果を確認して育てます。

**公開レビュー用の暫定版です。人による意味採点・読みやすさ確認・初見導入試行は未実施で、研修への正式採用が完了した版ではありません。**

## はじめ方

1. [導入マニュアル](docs/01-installation.md)で利用条件と設定方法を確認します。
2. 標準版は [エージェント指示](runtime/agent-instructions.txt)を設定します。
3. スキルが利用できる環境では [スキルZIP](runtime/meeting-minutes/meeting-minutes-skill.zip)と[スキル版指示](runtime/agent-instructions-with-skill.txt)を使います。講師用の解答・採点基準はエージェントに登録しません。
4. [架空の入力束](training/case01/input-bundle.txt)で動作を確認します。
5. [SSOTひな型](runtime/SSOT-template.txt)と[改善手順](docs/02-ssot-and-improvement.md)を使って育てます。

## 含まれるもの

- runtime：エージェント指示、スキルZIP、SSOTひな型。
- docs：導入、改善、研修進行、受入基準、仕様確認先。
- training：すべて架空の演習入力、改善前後、境界ケース。
- trainer：講師用採点基準、校正試料、読みやすさの観察基準。
講師用資料は、手動で原文と照合するための判定基準として収録しています。原本の集計器と候補指紋の検証環境は公開コピーに含めません。

会議入力を用意した後、利用者が作成を指示する方式です。会議終了時の無人実行や、外部送信、SSOTの自動更新は含みません。実機確認は一つの検証環境に限られ、別テナントでの利用可否・品質・速度を保証するものではありません。

## 公開範囲

このリポジトリは汎用化した研修用の別コピーです。実会議データ、アカウント情報、社内文脈、ブラウザー記録、認証情報、内部審査記録は含めません。架空のURLや疑似秘密文字列は境界演習の教材です。顧客向け原本および候補ZIPとは別版として管理します。

## 改善に参加する

変更はブランチで行い、入力根拠、期待する動作、実際の結果をPull Requestに添えてください。実会議の内容や認証情報をIssue・Pull Requestへ記載しないでください。
