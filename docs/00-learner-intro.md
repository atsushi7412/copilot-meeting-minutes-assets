# はじめに（受講者向け）

これはAI活用研修の受講者が、Microsoft 365 Copilotの議事録エージェントを自分で導入し、自分の業務に合わせて育てるための配布物。

## この配布物でできること

- Teamsの書き起こしとOutlookの会議設定から、根拠付きの日本語議事録初稿を作る標準版エージェントを作る。
- 任意で、カスタムスキル版（利用できる環境のみ）も作る。
- 架空の研修データで動作を確認した後、SSOTを自分の業務用に育てる。

## 進め方

1. [導入マニュアル](01-installation.md) に従って標準版エージェントを作成する。
2. 添付の研修ケースの入力で初稿を作成し、内容を根拠と照合して確認する。
3. [SSOTと育成](02-ssot-and-improvement.md) で、自分の業務用SSOTへ育て、編集後の反映方法を学ぶ。
4. 実務で使う前に、講師の案内に従って許可された実会議で確認する。

## 知っておくこと

- このエージェントは初稿を作るだけで、公開・送信・予定変更・タスク登録・SSOTの自動更新は行わない。
- 決定・担当・期限が不明な場合は「未定」と記載される。見た目が整っていても、必ず元の書き起こしや会議設定と照合する。
- 会議URLは、認証情報を含むと分かる場合や含むか判定できない場合、出力に元の文字列を表示しない。代わりに会議IDまたは「ID未提供・未確認」が記載される。
- 公式仕様の確認先は [Microsoft仕様確認](05-microsoft-sources.md) を参照する。
- 採点基準・模範例・講師用の評価ケースは受講者配布物には含まれない。分からないことは講師に確認する。
