# 議事録エージェントを育てる研修の進め方

この演習では、会議直後に議事録の初稿を得る体験から、コンテクストの整備、根拠の照合、改善までを一巡する。対象はAI活用研修の受講者。初回の時間配分は90分を提案する。

本資料は講師向けである。評価基準・ケース別の期待事項は [評価基準](../trainer/evaluation-checklist.md) を使う。達成基準と自動化の範囲は [達成基準と自動化](04-acceptance-and-automation.md) を参照する。

## 事前準備

講師は職場アカウント、エージェント作成可否、書き起こしの利用可否、ファイル添付とSSOT参照を確認する。実会議の確認前でも、演習は架空データで開始できる。講師用の正解例・採点基準は受講者が最初に作るエージェントへ登録しない。

## 実施

1. 目的と情報の役割を理解する〔10分〕。同じ書き起こしでも、呼称の照合と決定の扱いで品質が変わることを確認する。
2. 導入する〔20分〕。[導入マニュアル](01-installation.md) から標準版を作る。
3. 初稿を作る〔10分〕。C01を実行し、生成時間を記録する。
4. 根拠と照合する〔15分〕。決定、担当、期限、招待と出席、曖昧な呼称、会議URLの扱い（認証情報を含むURLが省略・保留されているか）を確認する。見た目が整っていても誤りがあれば指摘する。
5. 育てる〔20分〕。呼称辞書を1点改善し、同じ入力で変化を確認する。改善の理由と正本の更新方法を [SSOTと育成](02-ssot-and-improvement.md) に沿って説明する。
6. 別条件で試す〔10分〕。書き起こし欠落または定例会取り違えのケースを試す。進度の早い受講者には、旧版混入専用ケース（contamination）で指定外SSOTの混入を見抜く確認を加えてもよい。
7. 振り返る〔5分〕。何をAIへ任せ、何を確認し、次にどの業務へ使うかを記入する。

全ケースの原本受入評価は講師側で実施する。90分の演習内ですべての回帰評価が完了するとは扱わない。

## 受講者が残す成果

自分のエージェント、実行した入力と出力、根拠照合の記録、改善前後のSSOTまたは指示、変更理由、未確認事項を残す。実会議への移行は、認められた会議1件で同じ手順を実行して確認する。
