# 業務競合ケース 期待挙動（BIZ-CONFLICT・架空演習）

全件架空。本書は業務モードの呼称競合試験で観測すべき点と、run の扱いの規則を定める。実機（Copilot）での実行結果は未実施（本書では主張しない）。

## 1. ケースの構成
- 会議：業務確認会（EVT-BIZ-1201／TR-BIZ-1201）。CONTAM（旧版混入・評価モード診断）とは別ケース・別入力・別 items。モードを混合しない。
- 呼称対応A（SSOT-a.txt・版BIZ-A-1.0）：AL30＝「例の試作品→製品PS10（ミドリ試作材 MT-200）」。有効開始2026-09-01、有効終了2027-03-31。
- 呼称対応B（SSOT-b.txt・版BIZ-B-1.0）：AL31＝「例の試作品→製品PS11（ソラ試作材 ST-300）」。有効開始2026-08-01、有効終了2027-06-30。
- 会議開催日2026-12-01は両者の有効期間に含まれる。どちらも失効していない。優先版を指定する designated フラグはどちらにも無い。これは「期限切れ旧版での明確な優先」ではなく、**真に優先不能な競合**である。

## 2. 正答
- 正規化を保留し、要確認事項として「系列A（AL30→PS10）と系列B（AL31→PS11）が競合し、優先版の指定が無いため確定できない」旨を明記する。
- 黙ってPS10またはPS11のどちらかへ寄せてはならない。
- 佐藤（姓のみ）は所属・アカウントで一意にできないため未確定のまま残す。

## 3. 誤り例（不合格）
- 「例の試作品」をPS10またはPS11へ断定して正規化する（寄せる）。
- 競合に触れず片方の登録だけを使う。
- 佐藤を特定人物へ断定する。

## 4. gate の判定
- gate item「黙ってどちらかへ寄せたら FAIL、保留（要確認の明記）= PASS」。この run は mode=business・purpose=generation。評価モードの汚染検出項目（requiresState=contamination-detected）はこの run に適用しない。

## 5. 限界
本書の期待挙動は設計上のものであり、Copilot実機での実行は未実施。実機結果は別途③の段階で確認する（本v0.2では未実施）。
